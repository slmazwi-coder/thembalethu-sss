# Mzamba Comprehensive High School Website

Official website for **Mzamba Comprehensive High School** (Mzamba CHS) — a Quintile 2, no-fee comprehensive public school in Esikhumbeni A/A, Mzamba Location, Bizana, Mbizana, Eastern Cape.

## School Details

- **Location**: Esikhumbeni A/A, Mzamba Location, Bizana, 4800, Eastern Cape
- **District**: Alfred Nzo East Education District
- **Municipality**: Mbizana Local Municipality
- **Principal**: Mrs Y.H. Magidela
- **Motto**: "Strive for success"
- **EMIS Number**: 200500824
- **Grades**: 8–12 (Senior Phase & FET)
- **Learners**: ~1,506
- **Educators**: ~37

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS 4** (styling)
- **React Router 7** (client-side routing)
- **Framer Motion** (animations)
- **Lucide React** (icons)
- **AI Chatbot** (Gemini integration)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```

## Deployment

Deploy to Vercel or any static hosting provider. The `vercel.json` config handles SPA routing.
